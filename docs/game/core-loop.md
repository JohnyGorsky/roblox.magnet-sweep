# Core loop

## The fifteen steps (section 10)

```
 1  Enter the factory
 2  Sweep normal scrap
 3  Build MAGNET FLOW
 4  Find a rare Robot Part
 5  Is the magnet strong enough?
 6  Rip it free                     ← GRRRRR ... CLANG
 7  Security activates              ← SALVAGE BREACH
 8  Escape while carrying it        ← 20-45 s, slowed
 9  Reach a Service Hub
10  SECURED                         ← the payoff moment
11  Recycle scrap  OR  repair the robot   ← THE PINCH
12  Install the new part
13  Release the robot into the Arena
14  Spend the rewards
15  Go deeper
```

## Three nested loops

| Loop | Length | Question it answers |
|---|---|---|
| **Sweep** | 10-40 s | Is pulling things fun right now? |
| **Extraction** | 2-5 min | Can I get *that* thing home? |
| **Robot / Arena** | 10-40 min | Is my machine winning? |

The sweep loop must work standalone. The extraction loop gives the sweep a destination. The robot loop
gives extraction a reason and creates the scrap-versus-Coins pinch that sends the player back to the
sweep.

## The first ten minutes (section 74)

| Time | What happens |
|---|---|
| 0:00 | Spawn in the Workshop |
| 0:30 | First scrap collected — *tik tik tik* |
| 1:30 | Recycle. Coin explosion |
| 2:00 | First magnet upgrade bought |
| 3:00 | First meaningful rare part in sight |
| 4:00 | Pull it. Alarm |
| 4:30 | Escape |
| 5:00 | **SECURED** |
| 5:30 | First robot part installed |
| 6:30 | Robot released into the Arena |
| 7:00 | Robot fights |
| 8:00 | Player returns to the factory |
| 9:00 | *YOUR ROBOT HP LOW* |
| 10:00 | The complete loop is understood |

Nothing in this sequence is a tutorial screen. The onboarding is a prompt (**MOVE NEAR SCRAP**), an
arrow, and the fact that things shake when you get close.

## Magnet Flow

Continuous collection builds Flow **x1 → x5**, then **MAGNET RUSH**. Flow gives slightly faster pull, a
Coin multiplier, stronger VFX, a rising pickup pitch and a bigger visible field. It decays when you stop.

Flow is the mechanic that turns "walk around picking things up" into a rhythm with a fail state. It is
also the cheapest possible source of moment-to-moment tension, and it costs nothing to run.

## Where the player spends time

A healthy session is roughly: 55 % sweeping, 20 % extraction and escape, 15 % Workshop (recycle,
upgrade, install, repair), 10 % watching the Arena. If Workshop time climbs much above that, the menus
have become the game.
