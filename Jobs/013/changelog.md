# Changelog — Job #013

*The Workshop stops being a set. You can walk up to a station and use it.*

- 🧲 **The Magnet Lab works.** Walk up, press E, and the upgrade panel opens — the same one the
  UPGRADE button opens, with the same live prices, because it is literally the same panel.
- ♻️ **The Recycler works, and it asks you the question the game is built around.** It shows what
  your scrap is worth as **Coins** and as **robot HP**, side by side, same size, neither one
  pre-picked. 80 scrap is 1,920 Coins *or* 480 HP — you choose.
- 🔧 **Repair is honest about not being ready.** The robot arrives later, so the repair exit is
  greyed with its real number and says why. It does not pretend, and it does not silently do nothing.
- 🪧 **Every other station tells you what it will be** — the Robot Bay, the Part Archive, the Factory
  Entrance and the Scrap Arena each say which part of the game they are waiting on, instead of being
  a prompt that appears to be broken.
- 🚪 **Using one station closes another.** No more reading one station's message over another
  station's open panel.
